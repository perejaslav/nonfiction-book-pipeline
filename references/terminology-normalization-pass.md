# Terminology Normalization Pass for Non-Fiction Books

## Когда нужен

После того, как книга написана субагентами в разных контекстах, терминология неизбежно «плывёт»: одни памятники называются в латинской записи, другие — в русифицированной; одни склоняются по падежам, другие нет; встречаются смешанные шрифты (кириллица+латиница) и английские вставки.

## Подход: словарный поиск-и-замена

Не пытайтесь править по одному месту в 20+ файлах. Соберите полный словарь всех вариантов, которые нужно заменить.

```python
FIXES = {
    # 1. Русифицированные названия → стандарт
    'Гебекли-Тепе': 'Göbeklitepe',
    'Гёбекли-Тепе': 'Göbeklitepe',
    'Карахан-Тепе': 'Karahantepe',
    'Таш-Тепелер': 'Taş Tepeler',
    'Невалы-Чори': 'Nevalı Çori',
    'Чакмактепе': 'Çakmaktepe',
    'Сефертепе': 'Sefertepe',
    'Гюрджютепе': 'Gürcütepe',
    'Хамзан-Тепе': 'Hamzan Tepe',
    'Ташлы-Тепе': 'Taşlı Tepe',
    'Курт-Тепе': 'Kurt Tepe',
    'Харбетсуван': 'Harbetsuvan',
    'Сайбурч': 'Sayburç',
    'Чатал-Хююк': 'Çatalhöyük',
    'Чайоню': 'Çayönü',
    
    # 2. Падежные окончания на турецких названиях
    # Склоняем только родовое слово, не название
    'поселении Sayburç': 'поселения Sayburç',
    'памятнике Sayburç': 'памятника Sayburç',
    'Sayburçа': 'Sayburç',
    'Sayburçе': 'Sayburç',
    'Sayburçм': 'памятником Sayburç',
    'Harbetsuvanу': 'Harbetsuvan',
    'Höyükа': 'Höyük',
    'Yoğunburçе': 'Yoğunburç',
    
    # 3. Смешанный шрифт (кириллица+латиница)
    'Таş Tepeler': 'Taş Tepeler',
    'civilisation': 'цивилизация',
}
```

Затем выполнить однопроходную замену во всех md-файлах каталога chapters/.

```python
import os, glob

BASE = 'chapters/'
FIXES = { ... }  # см. выше

for fpath in glob.glob(BASE + '*.md'):
    with open(fpath, 'r', encoding='utf-8') as f:
        text = f.read()
    changed = False
    for old, new in FIXES.items():
        if old in text:
            text = text.replace(old, new)
            changed = True
    if changed:
        with open(fpath, 'w', encoding='utf-8') as f:
            f.write(text)
```

## Многоступенчатая верификация (4 круга)

По опыту: одна волна замен не вычищает всё. Планируйте 2–4 круга:

**Круг 1 — словарная замена:** описанный выше однопроходный скрипт.

**Круг 2 — поиск остатков:** `grep -rn "Гёбекли\|Карахан-тепе\|Таш-Тепелер\|Невалы-Чори" chapters/`. Обычно находятся формы с дефисом и варианты, не попавшие в исходный словарь.

**Круг 3 — падежные окончания на латинице:** `grep -rn "Sayburç[а-я]\|Höyük[а-я]\|Yoğunburç[а-я]" chapters/`. Поиск не должен найти ни одного вхождения.

**Круг 4 — смешанный шрифт:** `grep -rnP "[а-я][A-Z]" chapters/`. Ищет переходы кириллица→латиница внутри слова.

## Механизм исправления склонений турецких названий

Общее правило для научно-популярной книги на русском языке: **турецкие названия не склонять**. Падеж переносится на родовое слово:

| Вместо | Пишем |
|--------|-------|
| «на Sayburçе» | «на памятнике Sayburç» |
| «из Karahantepeа» | «с памятника Karahantepe» |
| «в Çatalhöyükе» | «в поселении Çatalhöyük» |
| «с Çakmaktepeм» | «с памятником Çakmaktepe» |
| «на Gürcütepe» | «на Gürcütepe» (без падежа, если нет родового слова — оставить в именительном) |

## Ловушки

1. **Автозамена в прологе.** Если в прологе была фраза «я использую Göbeklitepe, а не «Гёбекли-Тепе»» — замена превратит её в «я использую Göbeklitepe, а не «Göbeklitepe»». Это ломает смысл. **Решение:** после первого прохода прочитать строку пролога с объяснением, восстановить оригинальный русский вариант в кавычках.

2. **Согласование чисел.** Если в книге написано «12 подтверждённых памятников» и тут же перечислено 13 — это заметит любой читатель. **Решение:** писать «12+» или «12 основных» с оговоркой «в разных публикациях состав варьируется».

3. **«Civilisation» внутри русского текста.** Английские слова, оставшиеся после делегации субагентов, не видны на фоне латиницы, но режут глаз при чтении. Искать надо не только «civilisation», а любой паттерн latin_word_inside_russian_sentence.

4. **Склонение названий с уже поставленными родовыми словами.** Если после замены получилось «сюжетов поселения Sayburç» — это правильно. Если «сюжетов поселении Sayburç» — остаточная форма, её нужно ловить отдельным grep.
