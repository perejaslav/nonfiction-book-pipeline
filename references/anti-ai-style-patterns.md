# Anti-AI Style: Template Phrase Variants

## Why variant detection matters
Checking for exact phrases like "изменило всё" is not enough. Subagents generate variants that carry the same template effect. You must detect by root, not by exact string.

## Detection by root pattern

```python
import re

# Build combined pattern
patterns = [
    r'(не|нельзя|трудно|невозможно)\s+переоценить',           # переоценить
    r'навсегда\s+(вош[её]л[ао]?|остал[аоась]?|стал[ао]?)', # навсегда вошёл/остался
    r'перевернул[ао]?\s+',                                     # перевернул/а/о
    r'разрушил[ао]?\s+',                                       # разрушил/а/о
    r'открыл[ао]?\s+новую\s+страниц',                          # открыл новую страницу
    r'заставил[ао]?\s+переписать\s+учебники',                  # заставило переписать учебники
    r'стал[ао]?\s+символом',                                   # стал символом
    r'изменил[ао]?\s+вс[её]',                                  # изменил/а/о всё
    r'ключев[ая]+\s+сцен[аы]',                                 # ключевая сцена
    r'голос\s+прошлого',                                       # голос прошлого
    r'переписывать\s+учебники',                                # переписывать учебники
]

for line in text.split('\n'):
    line_lower = line.lower()
    if any(re.search(p, line_lower) for p in patterns):
        print(f"⚠️ {line[:120]}")
```

## Decision rules for each hit

| If the phrase... | Then... |
|-----------------|---------|
| States an obvious fact ("Мавзолей стал символом Китая") | **Leave** — it's descriptive, not a template |
| Repeats the user's thesis for the Nth time ("изменило всё") | **Replace** with a concrete result |
| Uses dramatic framing for a routine observation ("навсегда вошёл в историю") | **Replace** with neutral wording |
| Is deliberately ironic or in a quote | **Leave** — context justifies it |
| Replaces a worse template ("перевернула представления" replacing "изменила всё") | **Leave** — it's already an improvement |

## Common replacements

| Шаблон | Замена |
|--------|--------|
| навсегда осталась Люси | она и осталась Люси |
| трудно переоценить | было глубоким и многосторонним |
| изменило всё | перевернуло представления о... |
| пришлось переписывать учебники | описания пришлось пересматривать |
| перевернул эту формулу | опрокинул эту формулу |
| перевернул привычную логику | поставил под сомнение привычную логику |
| ключевая сцена эволюции | центральная сцена эволюции |

## Forbidden constructions (from booksmith-ru)

Эти конструкции запрещены в финальном тексте. При обнаружении — удалить или переформулировать.

**Список:**
- «Важно отметить, что...»
- «Не секрет, что...»
- «Как известно,...»
- «Следует обратить внимание на то, что...»
- «Нельзя не сказать о...»
- «Представьте себе...» (и варианты: «Представьте», «Представь себе»)

**Grep-детекция:**
```bash
grep -n -i "важно отметить\|не секрет\|как известно\|следует обратить\|нельзя не сказать\|представь\(те\)\? себе" manuscript.md
```

**Правило:** любое вхождение — заменять на прямую формулировку без вводной конструкции. Примеры замены:

| Фраза | Замена |
|-------|--------|
| Важно отметить, что X сыграл решающую роль | X сыграл решающую роль |
| Не секрет, что империя зависела от торговли | Империя зависела от торговли |
| Как известно, храмы были центрами хозяйства | Храмы были центрами хозяйства |
| Представьте себе, что вы оказались в Египте VII века | (удалить или заменить на прямое описание) |

Исключение: прямая речь персонажа или цитата из источника — оставить.|
