# Hybrid Book Writing — Main-Agent Core + Delegated Supplements

**Проверено на реальном проекте:** Taş Tepeler, ~68 500 слов, 28 глав, 2026-05-07.

## Зачем

Не все главы книги одинаково критичны для стиля, голоса и перекрёстных ссылок. Гибридный подход позволяет главному агенту писать ядро (ключевые нарративные главы, введение, заключение), а периферию (сравнительные обзоры, второстепенные памятники, приложения) делегировать субагентам.

## Когда применять

- Книга имеет отчётливое «ядро» (стилистически тонкие главы) и «периферию» (фактологически насыщенные, но стилистически менее критичные).
- Доступна параллельная делегация (2–3 субагента одновременно).
- У главного агента есть чёткое представление о стиле и структуре книги.

## Когда НЕ применять

- Книга полностью research-heavy с равномерной плотностью фактов (лучше Full Auto с foundation).
- Пользователь просит строго последовательный режим.
- Нет готового детального плана / факт-базы.

## Процесс

### 1. Распределение глав

| Пишет главный агент | Делегируется субагентам |
|---------------------|------------------------|
| Введение (пролог, методология) | Географический/климатический фон |
| История открытий (Nevalı Çori, Göbeklitepe, проект) | Второстепенные памятники |
| Ключевые памятники (Göbeklitepe, Karahantepe) | Сравнение с другими центрами |
| Архитектура и стелы | Диета и охота |
| Ритуал, символизм, смерть | Социальная организация |
| Заключение, приложения | Гендерный анализ |
| | Наука vs псевдонаука |

### 2. Контекст для субагента

Каждый субагент получает:
- Полный блок фактов (не менее 10–15 фактов на главу)
- Стилистические указания (тон, «возможно/вероятно», запрет клише)
- Целевой объём главы
- Точный путь сохранения файла
- Запрет на удаление существующего текста (если глава уже существует)

### 3. Волны и таймауты

- Запускать не более 2–3 субагентов одновременно.
- Таймаут (900 с) — нормальное событие. Файлы часто успевают записаться.
- Всегда проверять `ls chapters/` после каждой волны перед перезапуском.
- После завершения субагентов — точечный patch главным агентом (стиль, мосты, консистентность).

### 4. Компиляция

После получения всех глав: конкатенация в `manuscript.md`, проверка целостности (все главы на месте, нет пропусков), финальный patch мостов между главами.

## Результаты реального проекта

| Параметр | Значение |
|----------|----------|
| Всего глав | 28 |
| Написано главным агентом | 7 (1–7 + appendices) |
| Делегировано субагентам | 21 (2–3 волны по 2–3 агента) |
| Таймаутов субагентов | 1 из 6 |
| Файлов, потерянных при таймауте | 0 (все записались до таймаута) |
| Время выполнения | ~2 часа реального времени |
| Итоговый объём | 68 551 слово |

## Питфоллы

1. **Разные стили у субагентов** — компенсируется тем, что главный агент пишет стилистический «костяк».
2. **Таймауты** — проверять `ls chapters/`, не перезапускать вслепую.
3. **Полные файлы при таймауте** — субагент может успеть записать все 3 файла до таймаута сети.
4. **Перекрёстные ссылки** — главный агент пишет их в своих главах и добавляет в чужие при компиляции.
