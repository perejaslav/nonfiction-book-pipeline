# Editorial Eight-Point Pass for ~8.5→9/10 Manuscripts

## When to use

When a non-fiction manuscript is structurally complete (~60-80K words) and has been through Drafting + Expansion but needs a final editorial polish to reach 9/10. The user provides a detailed TZ (or you extract one).

## The 8-point checklist

### 1. Structure and navigation
- Verify table of contents: all part/chapter numbers and titles match actual files
- Check internal cross-references (`см. главу...`) point to correct chapters
- Verify the index/glossary/bibliography are aligned with the actual content
- Fix: wrong chapter numbers in index entries, orphan references, mismatched titles

### 2. Remove repetition of the main thesis
- Non-fiction books often repeat the central insight in every chapter
- Leave the full treatment in the Prologue and Conclusion only
- Replace repeats with chapter-specific concrete consequences (economy, ritual, cooperation, diet, hunting, architecture — not more "rewriting history")
- **Key test**: each chapter should have exactly ONE concluding thesis

### 3. Strengthen fact / hypothesis boundary
- Mark speculative claims: вероятно, по одной из гипотез, предварительные данные указывают
- Tighten absolute language: несомненно → по всей вероятности, доказывает → указывает на
- At the end of key chapters: add a mini-block "Что известно / Что предполагается / Что остаётся неизвестным"

### 4. Verify recent data (last 1-2 years)
- Books using 2024-2026 data are vulnerable: every fresh claim needs a source reference
- For each new finding: confirm via press release, journal article, or official project report
- Soften or remove: сенсация года, единодушное мнение without exact source
- Bibliography must reflect the actual citations used in the text

### 5. Reduce rhetorical overload
- Cut 10-15% of vivid scene-openers: представьте, мы только начинаем понимать, мир, который...
- Leave strong scenes only where they open a genuinely new topic
- Remove duplicate poetic final paragraphs
- Replace beautiful generalizations with concrete items: find, date, layer, object, method

### 6. Unify terminology
- Choose one naming convention (Turkish original vs Russified variants)
- First mention in Prologue announces the standard
- Scripted batch fix across ALL chapters (not just the ones you remember)
- Check diacritics: ş, ç, ğ, ü, ö, ı
- Maintain a small fix table for known Russian→standard substitutions
- Verify zero variants remain after the batch fix

### 7. Strengthen scientific apparatus
- After each chapter: 3-7 key sources, not a full bibliography
- Move weak or news-only sources to "recommended resources"
- For every contested claim: an anchor to a publication or official report
- All authors, dates, journal names: verified and consistently formatted

### 8. Rebuild the conclusion and epilogue
- Cut 15-25%: remove general reflection, keep the 3 precise takeaways
- Rewrite epilogue's summary: from 15 points to 10 (tighter, no repetition)
- Remove "история не заканчивается" in every variation
- Final code: shorter and harder, no repeating the Prologue

## Priority order
1. Structure, index, internal references, terminology
2. Fact-checking recent data and sources
3. Removing repetition and rhetorical endings
4. Stylistic polish and bibliography unification

## Common pitfalls
- **Index drift**: the index was accurate at chapter 10, but by chapter 28 new chapters had been inserted and references were never updated. Fix: read the index like a QA pass, not a generation pass.
- **Terminology bleed**: you fixed the big Russian variants but missed them in chapters written by sub-agents. Fix: run a comprehensive grep for ALL known variants across ALL files, not just the first cluster you found.
- **Conclusion inflation**: every rewrite makes the conclusion longer. Fix: set a hard word cap BEFORE rewriting.
