# Editorial Control Modes

## Auto Editorial
Use when the user wants end-to-end execution. Recommended order:
1. structural optimization;
2. repetition cleanup;
3. balanced fact-check;
4. style cleanup;
5. final proofread;
6. assembly.

## Approval-Gated Editorial
Use when the user wants checkpoints or when the intended changes may alter structure or emphasis.
1. structural review;
2. literary pass;
3. repetition pass;
4. fact-check;
5. style unification;
6. final proofread.

After each stage: summarize what changed, what remains, and ask whether to continue.
