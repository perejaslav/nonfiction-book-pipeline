# Single-Chapter Deep Research Pattern (без субагентов)

**Когда использовать:** пользователь просит развёрнутую научно-популярную главу / исследовательский обзор, но не запуск полного NFP (Foundation → Drafting → Expansion → Assembly). Задача средняя: 8–20 тыс. слов, 1 файл, 3–5 часов работы.

**Чем отличается от NFP:**
- Нет параллельных субагентов (`delegate_task`)
- Нет `foundation/` директории (terms, facts, voice — внутри главы)
- Нет Expansion волн (вся работа в одном цикле)
- Вывод: один `.md` файл вместо `manuscript.md` из склейки глав
- Всё делает ведущий агент напрямую

## Порядок действий

### 1. Составить карту исследования (todo)
Создать `todo` со списком тематических блоков. Пример для историческо-археологической темы:
- контекст и термины
- история открытия
- карта памятников
- архитектура и материальная культура
- социальная организация
- ритуалы и символика
- ключевой памятник (углублённо)
- научные споры и ограничения
- значение для мировой истории
- итоги, тезисы, вопросы

### 2. Параллельный сбор данных
Запустить `web_search` одновременно по 2–3 ключевым запросам, покрывающим разные углы темы. Не ждать один за другим — отправлять пачками.

### 3. Извлечение из ключевых источников
Для наиболее перспективных результатов — `web_extract` полного текста. Приоритет: официальные страницы проекта, Wikipedia, рецензируемые журналы (Antiquity, Archaeology Magazine), музейные сайты.

### 4. Добивка пробелов (итеративно)
После первичного сбора — точечные `web_search` для недостающих памятников, датировок, спорных вопросов. Маркировать сделанное в todo по мере наполнения.

### 5. Компиляция
Писать напрямую в `.md` файл. Структура:
- Заголовки `##` для разделов, `###` для подразделов
- Таблицы в markdown для сравнительных данных
- Выделение терминов **жирным** при первом упоминании с объяснением
- Цитаты из источников в виде blockquote `>`
- Разделение фактов и гипотез (явные маркеры «надёжно установлено» vs «гипотетически»)
- В конце: резюме (10–15 строк), список источников, 3 уточняющих вопроса для диалога

### 6. Питфоллы
- **Memory 90%+**: не забивать память деталями исследования — это временная задача. В память только: что и где написано, какой подход использован.
- **Неполнота данных**: если источник даёт противоречивую информацию — указывать обе версии с маркером «требует уточнения».
- **Устаревание**: новости по активно раскапываемым памятникам (Karahantepe 2025–2026) меняются быстро. Указывать год публикации.
- **Терминологическая ловушка**: популярные термины («древнейший храм») не всегда корректны научно. Всегда давать оговорку.
