# Operating Modes

Use `full-auto` when the user wants end-to-end execution from a strong synopsis with minimal interruptions.

Use `guided-editorial` when the user wants approval gates during revision after the draft/manuscript exists.

Use `sequential-safe` when delegation is unstable, the VPS is constrained, the topic is research-heavy, or the user asks for a careful linear workflow.

Use `editorial-only` when the manuscript already exists and the task is diagnosis, revision, fact-check, cleanup, or assembly.

Default preference for Slawix-style NFP work: `full-auto`, falling back to `sequential-safe` only when the environment or task risk justifies it.
