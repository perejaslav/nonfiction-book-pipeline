# Final Review Protocol for Historical Nonfiction

Use this after a complete manuscript exists and external/internal review begins.

## 1. External review ingestion

Parse the review into categories:

- critical factual
- terminology/entities
- structure/composition
- influence/overclaiming
- reconstruction/quotes
- tone/style cooling
- microcopy/proofreading
- production/PDF

Priority order:
critical factual > terminology > overclaiming > structure > reconstruction > style > proofreading > production.

## 2. Five-pass closeout

### Pass 1 — Structural coherence
- chapter order
- repeated material
- transitions
- chapter endings
- overloaded sections

### Pass 2 — Terminology/entities
- names and variants
- city/person/office associations
- specialist terms
- forbidden entity links
- glossary consistency

### Pass 3 — Fact-risk cleanup
- exact numbers
- named specialists
- artifacts and documents
- dates and chronology
- absolute firsts
- direct influence claims

### Pass 4 — Style cooling
- modern office/tech metaphors
- repeated authorial intensifiers
- sensational formulas
- unsupported poetic certainty

### Pass 5 — Production
- headings
- duplicate sections
- word count
- PDF build
- pdftotext sanity check
- deliver md + pdf

## 3. Micro-final pass rule

If the review says only a few places remain:

1. Do not run broad subagent passes.
2. Do not rewrite chapters.
3. Patch only named locations.
4. Verify old phrases are gone.
5. Build PDF immediately.
6. Deliver final files.

## 4. Stop condition

Stop editing when:
- no critical factual errors remain;
- remaining issues require external specialist review;
- review score is sufficient for the user's publication goal;
- user asks to finish;
- further changes are mostly taste/style preferences.

Do not chase 9+/10 indefinitely with LLM-only edits when the next improvement requires a domain expert.
