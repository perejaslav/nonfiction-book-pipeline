# Hallucination Patterns in NFP Subagents

## Case study: «Пески под полумесяцем: Арабское завоевание Египта» (May 2026)

### Observed patterns and their fixes

| # | Pattern | Example from session | Root cause | Fix |
|---|---------|---------------------|------------|-----|
| 1 | **Real name, wrong era** | Аль-Харис ибн Калада (ум. 634) назван врачом при армии Амра (поход 639–642) | Субагент взял реальное имя известного арабского врача эпохи Пророка и приписал его к более позднему событию, не проверив даты | Добавить в foundation-файл (facts.json) годы жизни/смерти для всех исторических лиц; верифицировать через поиск |
| 2 | **Inflated physical dimensions** | Стены Вавилона: «18 метров высотой, 3 м толщиной, башни 15 м диаметром» → реально: 10 м высота, 3 м толщина, 31 м диаметр | Субагент сгенерировал правдоподобные числа | Верифицировать все числовые параметры через Search Harvester |
| 3 | **Wrong historical period** | «Построен при Траяне (нач. II в.)» → реально при Диоклетиане (ок. 300 г.) | Субагент спутал императоров эпохи принципата и домината | Проверять даты основания строений, особенно римских |
| 4 | **Fabricated papyrus document** | «Пафнутий» — коптский чиновник, письмо «арабы уже здесь, ничего страшного, приходи домой, твоя семья скучает» → не существует | Субагент сгенерировал «типичный папирус переходного периода» как литературный приём | Полностью удалить такие пассажи при верификации; в промпте явно запретить ссылаться на конкретные папирусы без номера документа |
| 5 | **Semi-fabricated example** | «Псате из Арсинои, 13 свиней, 21 год хиджры, месяц сафар» — жанр (коптско-арабские папирусы с датами по хиджре) реален, но конкретный документ не идентифицирован | Субагент смешал реальный жанр с вымышленным экземпляром | Переписать как «типичный пример из папирусов того времени» без конкретных имени и чисел; или найти настоящий документ |
| 6 | **Fabricated direct speech** | «Греки ушли, но рынок работает. Цены на лён упали…» — вымышленная «цитата из папируса» | Субагент реконструировал «типичную» ситуацию и облёк её в кавычки | Перевести в косвенную речь или маркировать как гипотезу |
| 7 | **Unattributed quantitative estimate** | «Не менее 200–300 тысяч стрел за осаду», «8 миллионов литров воды в цистернах» | Субагент сгенерировал аппроксимацию без ссылки | Убрать или маркировать как «по оценкам археологов» с проверкой |

### Risk ranking

| Risk | Description | How to detect |
|------|-------------|--------------|
| 🔴 Critical | Прямая речь в кавычках без источника | grep `«[^»]{20,}»` + проверка каждого совпадения |
| 🔴 Critical | Конкретные имена не из facts.json | grep имён и сверка со списком известных лиц |
| 🟡 High | Точные числовые параметры | grep `\d{2,}\s*(метр|тысяч|миллион|динар)` + выборочная верификация |
| 🟡 High | Ссылки на «папирус из Фаюма/Оксиринха» | grep `папирус.*из\s*(Фаюм|Оксиринх)` + проверка |
| 🟢 Medium | Хронологические привязки (императоры, халифы, патриархи) | Сверка дат правления/жизни по энциклопедиям |
| 🟢 Medium | «Оживляющие примеры» — истории конкретных людей | Проверка существования имени в поиске |

### Verification tools

- **Search Harvester** (локальный, SearXNG на :8999, adapter на :8000): `POST /search` с целевым запросом
- **Wikipedia** — первичная верификация для имён, дат, числовых данных
- **Google Scholar / JSTOR** — для специфических академических утверждений (если доступны через Search Harvester)

### When to fix vs. when to flag

| Situation | Action |
|-----------|--------|
| Факт меняет историческое понимание | Исправить обязательно |
| Цифра слегка завышена/занижена | Подогнать под верифицированное значение |
| Вымышленное имя второстепенного персонажа | Удалить или заменить на обобщение |
| Прямая речь без источника | Убрать кавычки, перевести в косвенную речь |
| «Оживляющий пример» как жанр реален, но детали нет | Сделать обобщение («подобные папирусы свидетельствуют…») |
| Законченный вымысел (полностью сгенерированная сцена) | Удалить целиком |
