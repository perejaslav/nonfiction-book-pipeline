# Genre Narrative Patterns

## Purpose

Каждая глава получает жанровый метапаттерн на этапе chapter mapping. Это обеспечивает структурное разнообразие и предотвращает монотонность. Не использовать один и тот же паттерн для более чем 2 глав подряд.

## Nonfiction

```
Problem → Data → Interpretation → Practical conclusion → Bridge to next
```

Применение: тезисные книги, бизнес-литература, практические руководства.

## Popular Science

```
Puzzle → Context → Discovery/Research → Explanation → Significance → Bridge
```

Применение: научпоп, где центральный приём — интрига и её раскрытие.

## Historical

```
Era context → Event → Causes → Consequences → Connection to present → Bridge
```

Применение: историческая литература, где важны причинно-следственные цепи.

## Biography

```
Life situation → Hero's choice → Consequences → Personality evolution → Bridge
```

Применение: биографии, мемуары, портреты эпохи через фигуру.

## Business / Practical

```
Reader's problem → Model/Framework → Case study → Practical application → Bridge
```

Применение: бизнес-книги, методологии, практические руководства.

## Textbook / Guide

```
Learning goal → Theory → Example → Exercise → Summary → Bridge
```

Применение: учебные пособия, справочники, инструкции.

## Fiction / Narrative prose

```
Scene entry → Conflict/Action → Turn → Emotional shift → Cliffhanger/Bridge
```

Применение: художественная проза, нарративные вставки в нон-фикшн.

## Selection rule

- Определить жанр книги (или доминирующий жанр).
- Выбрать соответствующий базовый паттерн.
- Варьировать: не более 2 глав подряд с одинаковым паттерном.
- Для гибридных книг (история + бизнес) комбинировать паттерны по главам.

## Reference in templates

Запись в `chapter_map.md`:

```
- Narrative Pattern: problem→data→conclusion→bridge
```
