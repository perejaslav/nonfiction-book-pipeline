# Evidence Gaps Registry

Реестр неподтверждённых или слабо подтверждённых утверждений. Заполняется на этапе исследования и фактчекинга. Каждая запись должна быть разрешена (или понижен риск) до финальной валидации.

## Statuses

| Status | Meaning |
|--------|---------|
| нет источника | Утверждение не удалось подтвердить ни одним источником |
| один источник | Подтверждено единственным источником |
| веб-поиск недоступен | Не удалось выполнить веб-поиск для проверки |
| оспаривается | Источники расходятся в трактовке |
| требует осторожной формулировки | Есть основания, но требуется смягчённая формулировка |

## Risk Levels

| Risk | Description |
|------|-------------|
| ВЫСОКИЙ | Утверждение ключевое для главы и без источника. **Должен быть разрешён до финала.** |
| СРЕДНИЙ | Утверждение важно, но не критично. Может быть смягчено или удалено. |
| НИЗКИЙ | Утверждение второстепенно. Можно удалить без потери для главы. |
